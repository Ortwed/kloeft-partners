# Kløft Partners – hjemmeside (udkast)

Statisk one-page hjemmeside for Kløft Partners. Ingen build-trin – bare HTML og CSS.

- `index.html` – siden
- `styles.css` – styling
- `favicon.svg` – ikon
- `source-draft.html` – det oprindelige udkast, siden er bygget ud fra

Kør lokalt ved at åbne `index.html` i en browser, eller:

```bash
python3 -m http.server 8000
```

Siden udgives med GitHub Pages fra `main`-branchen.
